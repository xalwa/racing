# Автогонки ИДЗ 3 версия 3.0

Консольная программа на C для Linux. Реализованы четыре варианта с общими
правилами гонки, журналом и поклеточной анимацией:

| Программа | Запуск машин | Взаимодействие |
|---|---|---|
| race | Судья создаёт дочерние процессы | POSIX-память и неименованные семафоры |
| race-named | Судья создаёт дочерние процессы | POSIX-память и именованные семафоры |
| race-judge и race-car | Судья и машины запускаются независимо | POSIX-память и именованные семафоры |
| race-mq-judge и race-mq-car | Судья и машины запускаются независимо | POSIX-очереди сообщений и именованные семафоры |

Текущая версия находится в ветке v3.0. Предыдущие реализации сохранены
в ветках main и v2.0. Отчёт: [PDF](AKOS_report.pdf),
[Word](output/AKOS_report.docx), [исходный текст](REPORT.md).

## Сборка

Нужны Linux с поддержкой pidfd (ядро 5.3 или новее), GCC и Make.
Для проверок также Python 3. Для четвёртого варианта нужны POSIX-очереди
сообщений с размером сообщения до 8192 байт и очередью от 4 сообщений.
В обычном Linux эти пределы доступны по умолчанию.

```bash
make
```

Отдельные цели: `make unnamed`, `make named`, `make independent`, `make queues`.

## Обычный запуск

```bash
./race
./race-named
./race --delay 300 --log race.log
./race-named --strategy random --seed 7 --quiet --log race.log
```

По умолчанию: 3 команды по 2 машины, 4 дорожки по 24 клетки, 2 круга,
предел 100 раундов, seed 1, greedy. Стандартная гонка заканчивается
за 11 раундов. У каждой машины свой генератор с seed + id; одинаковые
параметры дают одинаковую гонку во всех четырёх вариантах в одном окружении.
Random отличается от последовательности общего генератора версии 2.

## Независимый запуск

В первом терминале запустить судью для двух машин:

```bash
./race-judge --session demo --teams 1 --cars 2 --wait 60
```

Во втором терминале:

```bash
./race-car demo 1
```

В третьем терминале:

```bash
./race-car demo 2
```

Судья ждёт подключения всех машин, затем начинает гонку. Машину также можно
запустить раньше судьи: она ждёт его до 10 секунд. Третий аргумент изменяет
это время, например `./race-car demo 1 60`.

Имя сессии — от 1 до 32 латинских букв, цифр, знаков `-` и `_`.
ID машины — от 1 до teams × cars. Повторный ID, лишний участник и второй
судья с тем же именем отклоняются. Для параллельных гонок нужны разные
имена сессий. Судья не запускает race-car автоматически.

Для обмена через очереди используются такие же команды и параметры,
но другая пара программ:

```bash
# Первый терминал
./race-mq-judge --session demo --teams 1 --cars 2 --wait 60
# Второй терминал
./race-mq-car demo 1
# Третий терминал
./race-mq-car demo 2
```

Подключать нужно машину соответствующего варианта. Обе независимые
реализации могут одновременно использовать имя demo: их ресурсы разделены.
В варианте с очередями состояние трассы передаётся сообщениями;
разделяемая память не используется.

## Анимация и журнал

В терминале после каждого перехода показан новый кадр: положение машин,
очередь, маршрут, бюджет, стоимость и событие. Цвет обозначает команду,
дополнительное выделение — текущую машину. По умолчанию пауза равна 120 мс.
Длинная трасса показывается участком вокруг текущей машины; проверено окно
от 80×24. Экраном и журналом управляет только судья.

`--no-animation` и `--delay 0` включают текстовый режим. Запрет анимации имеет
приоритет над задержкой при любом порядке аргументов. При --quiet,
перенаправлении stdout или TERM=dumb анимация и паузы отключаются.
Журнал всегда текстовый, без ANSI, и сохраняет подробности при --quiet.

## Параметры судьи

| Аргумент | Диапазон |
|---|---|
| --teams N | 1–8 команд |
| --cars N | 1–4 машины в команде |
| --lanes N | 1–6 дорожек |
| --length N | 3–120 клеток; больше общего числа машин |
| --laps N | 1–100 кругов |
| --rounds N | 1–10000 раундов |
| --seed N | 0–4294967295 в текущем Linux |
| --strategy S | greedy или random |
| --log FILE | Полный текстовый журнал |
| --quiet | На экране только параметры и итоги |
| --delay MS | 0–5000 мс, по умолчанию 120 |
| --no-animation | Текстовый режим без пауз |
| --session NAME | Обязательно для race-judge и race-mq-judge |
| --wait SEC | Независимые судьи: ожидание всех машин, 1–60 секунд, по умолчанию 10 |

## Завершение

Гонка заканчивается после финиша/схода всех машин, по пределу раундов
или SIGINT/SIGTERM. Начатый раунд завершается, новый не начинается.
Ctrl+C в терминале независимой машины также запрашивает остановку гонки.
Длинные паузы отменяются, экран и курсор восстанавливаются.

Судья ждёт выхода участников и удаляет свои ресурсы. Гибель или остановка
машины обнаруживается без бесконечного ожидания. Коды судьи: 0 — штатное
завершение, 1 — ошибка, 130/143 — обработанные SIGINT/SIGTERM. Отдельная
машина возвращает 130/143, если сигнал получен в её терминале.

SIGKILL нельзя обработать. Если погибает независимый судья, оставшиеся
машины удаляют ресурсы сессии. При одновременном SIGKILL всех независимых
участников удалить имена некому; это ограничение аварийного завершения.

## Проверки

```bash
make test
make test-processes
make test-display
make test-variants
```

Проверяются правила, реальные процессы, кадры, журналы, ошибки запуска
и освобождения, независимое подключение и изоляция параллельных гонок.
Архитектура описана в ARCHITECTURE.md, результаты — в AUDIT.md.
