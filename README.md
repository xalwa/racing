# Автогонки ИДЗ 4

Сетевая версия на C для Linux. Судья хранит трассу и управляет очередью
ходов. Каждая машина выбирает маршрут и отправляет его судье по TCP.
Наблюдатель получает кадры всей гонки и показывает итоговые места.

Отчёт ИДЗ 4: [PDF](AKOS_report.pdf), [Word](output/AKOS_report.docx),
[текст отчёта](REPORT.md).

## Сборка и запуск

Собрать программы командой:

```bash
make network
```

Запускать строки в отдельных терминалах из каталога проекта. Первым
запускается судья. Можно открыть несколько наблюдателей одной и той же
командой.

```bash
./race-server 127.0.0.1 5000 --teams 1 --cars 2 --wait 60
./race-watch 127.0.0.1 5000
./race-driver 127.0.0.1 5000 1
./race-driver 127.0.0.1 5000 2
```

Без наблюдателя судья и машины показывают только свой обмен. С
наблюдателем видна вся трасса и каждое перемещение по клеткам. В терминале
судьи параметр `--delay` задаёт интервал кадров в миллисекундах (по умолчанию
120). Для быстрого запуска можно указать `--delay 0`. Наблюдатель принимает
`--no-animation` для текстового вывода, который также включается при
перенаправлении вывода в файл. Все параметры судьи доступны через `--help`.

Для запуска на разных компьютерах вместо `127.0.0.1` укажи доступный
IP сетевого интерфейса компьютера с судьёй. Порт должен быть доступен
с машины, где запущены клиенты. Программы принимают числовые IPv4 и IPv6.

## Подключение и завершение

Судья начинает гонку после регистрации всех машин. В гонке может быть
до 16 наблюдателей одновременно. Наблюдатель может выйти по Ctrl+C
и запуститься снова с той же командой. Он сразу получает текущий кадр.

Чтобы разрешить возврат машин, запусти судью с `--reconnect 15`. Если
машина отключилась, судья ждёт её, когда приходит её очередь, до 15 секунд.
Запусти машину с тем же ID. Уже принятые ходы сохраняются, а незавершённый
ход выдаётся повторно. При `--reconnect 0` (по умолчанию) разрыв связи с
активной машиной прекращает гонку. Таймаут ответа на ход задаёт
`--turn-timeout`, по умолчанию 10 секунд.

По завершении гонки участники получают результаты. При Ctrl+C в терминале
судьи подключённые клиенты получают сообщение об остановке и выходят.
Судья ограничивает время доставки, чтобы остановка не зависела от
соединения, которое перестало читать данные.

## Проверки

```bash
make test-tcp
make -B test
```

Первый запуск проверяет сетевую часть. Второй также пересобирает программы
и прогоняет тесты модели гонки и реализаций ИДЗ 3. Для тестов нужен Python 3.
Формат обмена описан в [PROTOCOL.md](PROTOCOL.md).

Предыдущие задания находятся в ветках `main`, `v2.0` и `v3.0`.
Отчёт ИДЗ 3 доступен в ветке `v3.0`.
