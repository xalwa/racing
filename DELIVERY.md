# Комплект ИДЗ 3 Автогонки

Куслин Глеб Витальевич, БПИ252. Вариант 20. Версия 3.

В архив включены исходники всех четырёх реализаций, Makefile, тесты,
документация, PDF и редактируемый отчёт Word. Общие правила находятся
в race.c, способы взаимодействия — в processes.c и queues.c.

После распаковки открыть каталог проекта и выполнить:

```bash
make
./race --delay 120
```

Вторая реализация запускается командой ./race-named. Для независимых
программ пары race-judge/race-car и race-mq-judge/race-mq-car запускаются
в отдельных терминалах; готовые примеры находятся в README.md.

Полная проверка:

```bash
make -B test
```

Результаты и границы проверки описаны в AUDIT.md. Файл SHA256SUMS внутри
архива содержит контрольные суммы включённых файлов. В Linux их можно
проверить командой sha256sum -c SHA256SUMS из распакованного каталога.

Бинарные файлы, журналы запусков, кеши Python и каталог .git в комплект
не входят. Предыдущие версии остаются в ветках исходного репозитория.
